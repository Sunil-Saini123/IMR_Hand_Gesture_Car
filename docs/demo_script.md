# Demo video script (2–3 minutes)

1. Show the Webots arena and explain that the robot is simulated.
2. Show webcam processing and explain MediaPipe landmarks → UDP → Webots.
3. Demonstrate keyboard fallback and gesture-based stop/forward.
4. Demonstrate assisted mode near an obstacle at low speed.
5. Show an A* test-grid route and explain how it will be integrated with the map.
6. Show measured pose-error and gesture-classification plots after experiments.
7. State working features, measured results and remaining limitations honestly.

Do not present untested/planned features as completed results.
